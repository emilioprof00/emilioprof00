# 🖥️ Laboratorios virtuales

## 🎯 Objetivo

Documentar la instalación, configuración y administración de laboratorios de ciberseguridad mediante VMware Workstation.

## 🧰 Tecnologías utilizadas

- VMware Workstation
- Kali Linux
- Ubuntu Server
- Windows Server
- Windows 10/11
- Máquinas virtuales vulnerables para prácticas autorizadas

## 📂 Prácticas

- [ ] Instalación y configuración de VMware.
- [ ] Creación de máquinas virtuales.
- [ ] Configuración de redes virtuales.
- [ ] Verificación de conectividad entre máquinas.
- [ ] Aislamiento de los sistemas destinados a pruebas.

## 🧪 Evidencias

En esta sección añadiré diagramas, capturas y resultados obtenidos durante las prácticas.

## 🛡️ Seguridad

Las pruebas se realizarán en entornos propios o autorizados. No se publicarán credenciales ni información sensible.

## 📝 Estado del proyecto

En desarrollo. La documentación se actualizará conforme complete cada práctica.
